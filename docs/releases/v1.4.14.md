## 飞驴 v1.4.14 / Feilv v1.4.14

- 使用默认设备名称时，可在提示中设置名称和头像，也可以选择稍后再说；如果仍使用默认名称，7 天后再次提醒。
- 可为在线设备设置仅自己可见的备注，显示为“昵称(备注)”，并支持按备注筛选。
- 在线设备的发送按钮旁新增共享目录入口，可在独立窗口浏览并下载对方的共享文件。
- 本地共享目录支持自定义显示名称；下载共享文件时可选择保存目录，同名文件不会被覆盖。
- 设置中增加项目名称、源码地址和 .NET 构建信息，窗口标题显示版本号。
- 更新后保持原有窗口状态，并在右下角提示更新成功。从旧版首次更新到本版时，旧版更新助手尚不能传递窗口状态；之后的更新会保持状态。

---

- When using the default device name, set a name and avatar in the prompt or choose to do it later. If the name remains unchanged, the reminder returns after seven days.
- Add private local remarks to online devices. Names appear as "name(remark)", and the device filter also searches remarks.
- Open an online device's shared folders from its row, then browse and download files in a separate window.
- Assign display names to local shared folders. Choose a destination when downloading a shared file; existing files are not overwritten.
- Settings now show the project name, source repository and .NET build information. The window title includes the app version.
- Updates preserve the window state and show a success notification in the corner. When upgrading from an older version to this release, the old updater cannot yet pass the window state; subsequent updates preserve it.
