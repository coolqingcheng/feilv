## 飞驴 v1.4.9 / Feilv v1.4.9

- 设置按钮旁新增太阳 / 月亮 SVG 图标，点击即可切换亮暗主题并自动保存，无需进入设置页。
- 跟随系统时按照当前实际亮暗状态切换，设置中仍可恢复“跟随系统”。
- 标题栏适配窄窗口，中英文标题按可用空间显示；切换主题保留当前页面和接收人选择。
- 主题配置仅在本地异步保存，保存失败时恢复原主题并提示。

---

- Added a sun / moon SVG shortcut beside Settings. Click to switch between light and dark themes and save your choice immediately.
- The shortcut follows the actual appearance when using the system theme. You can restore System in Settings.
- Adjusted the title bar for narrow windows in both languages. Theme changes preserve your current page and recipient selection.
- Theme preferences are saved locally and asynchronously. If saving fails, the previous theme is restored with an error message.

更新与卸载保留本地数据。 / Updates and uninstallation preserve local data.
