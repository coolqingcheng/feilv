## 飞驴 v1.4.13 / Feilv v1.4.13

- Windows 继续提供 EXE 安装包；macOS Apple Silicon 改为 DMG，Linux x64 和 ARM64 改为 AppImage。
- macOS 和 Linux 的配置与文件保存在用户数据目录，可在设置中查看位置。
- 新包支持下载校验后由用户确认更新；数据不会随程序替换。
- 旧 macOS/Linux 压缩包首次切换需手动安装，并按需迁移 Data、Files、Images 和 qr-http。
- macOS 应用尚未公证；Linux AppImage 可能需要 FUSE 2，也可使用提取运行模式。

---

- Windows keeps the EXE installer; macOS Apple Silicon now uses a DMG and Linux x64/ARM64 use AppImages.
- macOS and Linux store configuration and files in the user's data directory, shown in Settings.
- New packages download and verify updates before confirmation; replacing the app preserves data.
- Users of older macOS/Linux archives must install the new package manually and migrate Data, Files, Images and qr-http as needed.
- The macOS app is not notarized. Linux AppImages may require FUSE 2 or extract-and-run mode.
