## 飞驴 v1.4.8 / Feilv v1.4.8

- 新增简体中文和 English 界面，默认跟随系统语言；设置中切换后立即生效，保存到 `Data/config.xml`。
- 主界面、收发记录、接收提示、共享目录、托盘菜单、文件选择器及更新提示支持中英文；文件名、设备名和更新说明保留原文。
- 手机扫码页面支持浏览器语言和独立的中英文切换，上传与下载保持流式处理。
- 同一个 Windows 安装包支持中英文安装向导，继续提供五个平台的 Native AOT 包。
- README 提供完整中英文版本及对应语言的真实界面截图。

---

- Added Simplified Chinese and English interfaces. Feilv follows your system language by default; changes in Settings apply immediately and are saved to `Data/config.xml`.
- Translated transfers, history, receive prompts, shared folders, tray menus, file pickers and update prompts. Filenames, device names and authored release notes stay unchanged.
- The QR webpage follows your browser language and offers an independent language switch. Uploads and downloads remain streamed.
- One Windows installer includes both wizard languages. Native AOT packages remain available for all five targets.
- Added complete Chinese and English READMEs with actual screenshots in each language.

更新与卸载保留本地数据。 / Updates and uninstallation preserve local data.
